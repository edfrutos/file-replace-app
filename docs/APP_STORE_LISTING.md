### Description (2061/4000)

```
Replacer finds one or more pieces of text in every file of a folder and replaces them only where you decide, after reviewing every match. And if you change your mind, you undo the replacement from the history.

Made for changing URLs, names, paths or configuration values repeated across many files without opening them one by one, and without the risk of a blind "replace all".

SEVERAL CHANGES AT ONCE
• Add as many "find → replace" pairs as you need: they are applied in a single pass and never chain into each other.
• Save lists of pairs as recipes and reuse them ("Migrate domain", "Rename product"…).
• Import pairs from a CSV file or an exported spreadsheet.

REVIEW BEFORE YOU CHANGE
• No file is checked by default: you decide.
• Review every match with its line and the before → after change, and exclude the ones you want to keep.
• Open the full content of any file with every match highlighted, read-only.
• If a file changes after the search, Replacer leaves it untouched and tells you.

UNDO AT ANY TIME
• Before modifying a file, Replacer saves a copy next to the original (.replacer-backup).
• The history keeps your last 50 replacements: restore a whole batch or a single file.
• It never overwrites a file you edited after the replacement.

BUILT FOR MACOS
• Drag a folder onto the window or the Dock icon.
• Right-click a folder in Finder ▸ Services ▸ Find and Replace with Replacer.
• Filter by name with patterns such as *.html, config* or .env*, and search subfolders down to the depth you choose.
• English and Spanish interface; light, dark or automatic appearance.

SAFETY
• Works only with UTF-8 text: skips binaries, non-UTF-8 files and files larger than 5 MB, and tells you how many were skipped.
• Ignores noise folders such as .git or node_modules.
• Read-only files are reported and left untouched.

PRIVACY
• No internet connection, no analytics, no accounts.
• Only accesses the folders you choose.
• Collects no data.

Replacer searches for exact text (not regular expressions), so what you type is exactly what gets changed.
```
